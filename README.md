# Form Communities merch print files

Print-ready artwork for the [Form Communities Shop](https://shop.formcommunities.org) (transparent PNG, sized for the print area).
Files here are handed to our print partner (Printful) when products are created, and are the same files offered as free downloads in the shop.

- `og/` — OG line: each program's plain logo (left chest). `-dark` = for dark shirts, `-light` = for light shirts.
